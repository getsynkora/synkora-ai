# Use Qdrant

Qdrant is a strong fit when you want a dedicated vector store with good performance and operational clarity.

## Use Qdrant When

- vector retrieval is a core part of your workload
- you want more control than a fully managed hosted provider
- you are already comfortable operating infrastructure alongside Synkora

## Configuration Checklist

- provision Qdrant
- configure connectivity and credentials
- create or map collections for the right retrieval domains
- test ingestion and retrieval before moving production traffic

## Tradeoff

Qdrant gives you control and strong retrieval behavior, but you own more of the operational footprint than with a managed service.
