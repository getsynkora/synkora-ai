# Deploy a WhatsApp Bot

WhatsApp is useful when the agent needs to meet users in a customer-facing or mobile-first messaging environment.

## Common Use Cases

- customer support
- lead qualification
- order or account assistance
- appointment and follow-up workflows

## Setup Flow

1. Create the target agent
2. Configure WhatsApp Business credentials
3. Add the bot in Synkora
4. Attach it to the agent
5. Validate behavior carefully on real conversation flows

## Advice

- keep the first release extremely narrow
- test failure and escalation behavior early
- treat customer-facing automation as a product surface, not just a transport
