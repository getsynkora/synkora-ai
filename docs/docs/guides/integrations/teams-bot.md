# Deploy a Microsoft Teams Bot

Use Teams when your users already live in Microsoft’s collaboration environment and want agents alongside normal internal communication.

## Recommended Flow

1. Create and test the agent first in the dashboard
2. Configure the Teams bot in Synkora
3. Complete the Microsoft-side app setup and permissions
4. Bind the bot to the correct agent
5. Test with a small internal audience

## Best Practices

- keep the first deployment internal
- avoid broad tool permissions until behavior is stable
- document ownership of the bot configuration
- pair Teams bots with narrow use cases such as HR, IT help, or internal knowledge access
