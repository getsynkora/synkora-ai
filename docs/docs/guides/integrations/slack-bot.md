# Deploy a Slack Bot

Slack is one of the strongest fits for Synkora because it puts agents inside existing team workflows.

## Typical Slack Use Cases

- support triage
- internal copilots
- engineering assistants
- escalation and notification flows

## Setup Flow

1. Create the agent in Synkora
2. Create or connect the Slack app/bot configuration
3. Authorize the workspace
4. Map the bot to the target agent
5. Test in a controlled channel

## Before You Roll Out

- keep the initial channel scope narrow
- make the agent’s persona explicit
- verify tool permissions carefully
- confirm billing and usage visibility for the tenant

## Design Advice

Slack works best when the agent has:

- focused instructions
- clear escalation boundaries
- concise response style
- knowledge or tools tied to one team function
